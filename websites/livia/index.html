About Livia

Livia is a Windows automation library designed to move macro development beyond isolated, one-off scripts. Instead of reimplementing common functionality for every project, developers can build on a shared foundation of reusable services, UI components, input simulation, and system utilities.

Although Roblox automation is its primary use case, Livia's general-purpose functionality can also be used independently to build Windows applications.

Technical Highlights

  • DXGI Frame Capture — Native C++ screen capture using DirectX Graphics Infrastructure and GPU staging resources.
  • Windows Security Integration — VSS-backed DPAPI cookie decryption for accessing browser-stored authentication data.
  • Native Windows APIs — Low-level system integration through Win32, Windows Runtime, and native interop.
  • Reusable UI Components — Common WPF controls for building consistent Windows application interfaces.
  • Multi-Instance Support — Roblox singleton mutex handling and multi-account launching.
  • Asynchronous Services — Log monitoring, window focus monitoring, waitable timers, Discord webhooks, and other reusable utilities.

Getting Started

Livia targets .NET 10 on Windows 11 (build 22000 or later). It can be installed into an existing C# project through NuGet. 

dotnet add package Livia

Python applications can use the official Python bindings, which expose Livia's functionality through Python.NET. 

pip install livia-python

Visit the repository for installation instructions and source code.

API Overview

Livia exposes a collection of reusable APIs for common automation tasks. The following are examples of the functionality available to consuming applications.

User Interface

  • CommonTab — Creates reusable UI tabs.
  • CommonIntegerInput — Integer input controls.
  • CommonStringInput — String input controls.
  • CommonActionInput — Combined action buttons and input fields.
  • CommonToggle — Toggle controls for application settings.

Input Simulation

  • HotkeyService — Registers hotkeys with optional modifiers.
  • Mouse — Mouse movement, clicking, and scrolling.
  • Keyboard — Keyboard press and release simulation.
  • VirtualKeys and ModifierKeys — Named virtual key codes and modifier flags.

Windows Services

  • DxgiFrameProvider — Captures screen regions through DXGI.
  • WindowFocusMonitor — Detects target window focus changes.
  • RobloxLogMonitor — Monitors log files using regular expressions.
  • WaitableTimerService — Schedules asynchronous callbacks.
  • WindowsOcrService — Uses the native Windows OCR engine.
  • DiscordWebhookService — Sends messages through Discord webhooks.

Roblox Utilities

  • RobloxServerUtils — Retrieves private server information and join links.
  • RobloxPlayerUtils — Launches multiple accounts into an experience.
  • RobloxSingletonMutexClosingService — Handles Roblox singleton synchronization objects.
  • BrowserUtils — Provides browser cookie access utilities.

This is a selection of the available APIs, not an exhaustive reference. See the repository for the complete implementation and usage examples.

Reference Macros

The Livia repository also contains reference macro applications demonstrating how the library can be used in practice. These projects are separate from the core library and serve primarily as examples of implementation.

  • Auto Order — My Cafe
  • Auto Rejoin — General-purpose Roblox automation
  • Singleton Mutex Closer — Roblox instance management

Reference macros are maintained on a volunteer basis and are not guaranteed to remain functional following updates to Roblox or their respective games.
